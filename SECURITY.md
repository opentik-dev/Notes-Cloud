# Security policy

Please do not report security vulnerabilities in public Issues. Send a private
report to the repository maintainers first. Never include real passwords,
Cloudflare tokens, production database exports, or user data in Issues, Pull
Requests, or commits.

Before a public deployment, configure `ADMIN_EMAIL`, replace the placeholder
D1 database ID, review cookie/security settings, and keep all credentials in
Cloudflare secrets or a private local override.
