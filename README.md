# دفتر سحابي | NotesCloud

لإعداد جهاز جديد واستئناف العمل، راجع [HANDOFF.md](HANDOFF.md) أولًا.

منصة ملاحظات سحابية متعددة المستخدمين، عربية أولًا، تعمل داخل Cloudflare Workers وتستخدم D1 (SQLite) لحفظ البيانات بأمان. صُممت NotesCloud لتكون مساحة هادئة وسريعة للكتابة والتنظيم، مع دعم النصوص والصور والرسومات المتجهة.

English summary: NotesCloud is a multi-user, Arabic-first cloud notes platform built on Cloudflare Workers and D1. It provides private notes, Markdown editing, notebooks, tags, media assets, import tools, and responsive light/dark/system themes.

الرابط المنشور سابقاً: https://notes.opentik.win (قد يحتاج إعداد نشر مستقل).

قاعدة D1 الافتراضية اسمها `notes-db`. لا يحتوي المستودع العام على معرّف قاعدة
الإنتاج؛ ضع معرّفك الخاص في إعداد النشر فقط.

## لماذا NotesCloud؟

- خصوصية لكل مستخدم مع جلسات آمنة وعزل كامل للملاحظات والدفاتر والعلامات.
- تجربة عربية واتجاه RTL متجاوب على الهاتف واللوحي وسطح المكتب.
- محرر Markdown مع وضع تحرير ومعاينة منفصلين، وإدراج الصور ورسومات SVG.
- تنظيم عملي عبر الدفاتر والعلامات والأرشيف والبحث والفرز وطرق عرض البطاقات والشبكة والقائمة.
- استيراد من Obsidian وJoplin وGoogle Keep، مع نسخ احتياطي JSON.
- ألوان ومظاهر فاتح/داكن/حسب النظام، مع شعار وهوية NotesCloud.

## المساهمة في التطوير

نرحب بالمساهمين في تحسين المحرر، تجربة الهاتف، الأداء، الترجمة، الاختبارات، والتكاملات. ابدأ بقراءة [CONTRIBUTING.md](CONTRIBUTING.md)، ثم افتح Issue يصف المشكلة أو الاقتراح قبل إرسال Pull Request.

## نشر المستودع على GitHub

المشروع مهيأ كمستودع عام: يحتوي على ترخيص MIT، وCI، وقوالب Issues وPull
Requests، مع استبعاد الأسرار والنسخ الاحتياطية. أنشئ مستودعاً عاماً فارغاً
باسم تختاره على GitHub، ثم نفّذ من مجلد المشروع:

```bash
git remote add origin https://github.com/<owner>/<repository>.git
git push -u origin main
```

بعد ذلك اجعل `main` فرع الحماية، وفعّل مراجعة Pull Request، ولا تضع إعدادات
Cloudflare الخاصة بالإنتاج في GitHub. يحتاج كل مساهم إلى نسخ فرعه، تشغيل CI
محلياً، ثم فتح Pull Request.

## التشغيل لأول مرة

1. ثبّت الاعتمادات:

```bash
npm install
```

2. أنشئ قاعدة D1، ثم ضع `database_id` الذي يظهر في الناتج في نسخة محلية خاصة
من `wrangler.toml` (لا ترفع معرّف الإنتاج إلى مستودع عام إن كان حساساً لبيئتك):

```bash
npx wrangler d1 create notes-db
```

3. طبّق الجدول على قاعدة التطوير المحلية للتجربة:

```bash
npm run db:local
npm run dev
```

إذا كانت لديك قاعدة قديمة من النسخة الأولى، طبّق ترحيل مساحة العمل والمصادقة:

```bash
npx wrangler d1 migrations apply notes-db --local
npx wrangler d1 migrations apply notes-db --remote
```

افتح الرابط الذي يظهره Wrangler، غالبًا `http://localhost:8787`.

## النسخ الاحتياطي والاستعادة

ينشئ الأمر التالي مجلداً قابلاً للنقل يحتوي نسخة من المصدر، وملف manifest،
وتصديراً SQL لقاعدة D1 المحلية:

```bash
npm run backup:local
```

لتصدير قاعدة D1 البعيدة بعد تسجيل الدخول إلى Cloudflare:

```bash
npm run backup:remote
```

في Windows يمكن تشغيل `./scripts/backup.ps1 --local`، وفي Linux/macOS
`./scripts/backup.sh --local`. انسخ مجلد `notescloud-backup-*` إلى جهاز تخزين؛
ولا تضعه داخل GitHub لأنه قد يحتوي بيانات المستخدمين. يحتوي المجلد على
`RESTORE.md` بخطوات الاستعادة على Windows أو Linux أو macOS. يجب تثبيت Node.js
LTS وWrangler على الجهاز الجديد، ثم إعادة ضبط `database_id` وصلاحيات Cloudflare.

## النشر على Cloudflare

بعد وضع `database_id` الصحيح في إعداد خاص غير منشور:

```bash
npm run db:remote
npm run deploy
```

سيظهر رابط التطبيق بعد النشر. يتم تقديم الواجهة والـAPI من نفس الرابط:

- `GET /api/notes` — قراءة الملاحظات
- `POST /api/notes` — إنشاء ملاحظة (`title`, `content`, `tags`, `notebook_id`, `color`)
- `PATCH /api/notes/:id` — تعديل أو أرشفة ملاحظة
- `DELETE /api/notes/:id` — حذف ملاحظة
- `GET /api/export` — تصدير نسخة JSON احتياطية

## الحسابات والخصوصية

- `POST /api/auth/register` — إنشاء حساب (`name`, `email`, `password`)
- `POST /api/auth/login` — تسجيل الدخول
- `POST /api/auth/logout` — إنهاء الجلسة
- `GET /api/auth/me` — التحقق من الجلسة الحالية
- كل جلسة تستخدم ملف Cookie من نوع `HttpOnly`, `Secure`, `SameSite=Lax` مع انتهاء صلاحية بعد 30 يومًا.
- كلمات المرور لا تُحفظ كنص صريح؛ تُحفظ كبصمة SHA-256 مملحة ومتكررة 100 مرة داخل Worker.
- كل استعلام للملاحظات والدفاتر والعلامات والإعدادات مرتبط بمعرّف المستخدم، لذلك لا يستطيع مستخدم قراءة بيانات مستخدم آخر عبر الـAPI.
- الملاحظات القديمة غير المالكة تُنسب تلقائيًا إلى أول حساب يتم إنشاؤه بعد الترحيل.

## ما تمت إضافته

- محرر Markdown مع معاينة حية.
- أزرار العناوين، العريض، المائل، القوائم، الاقتباسات، الروابط، الكود والجداول.
- تراجع وإعادة باستخدام سجل المتصفح.
- استيراد ملاحظات Obsidian من ملفات Markdown أو مجلد كامل.
- استيراد Joplin بصيغة Markdown/JSON، وGoogle Keep من ملفات Takeout بصيغة HTML.
- دفاتر، علامات، بحث، فرز، أرشيف، تعديل وحذف.
- شعار NotesCloud بصيغة SVG خفيفة في شاشة الترحيب والشريط العلوي.
- أزرار مظهر واضحة: فاتح، داكن، حسب النظام.
- تخزين صور صغيرة ورسومات SVG داخل جدول D1 `assets` مع عزل كل أصل حسب المستخدم.
- محرر SVG حر بسيط داخل محرر الملاحظات، وزر لإدراج الصور من الجهاز.
- صفحة إعدادات للمظهر، طريقة المحرر، الترتيب، النسخ الاحتياطي ومزود المزامنة.
- خيار WebDAV/Nextcloud ظاهر في الإعدادات كمرحلة تكامل لاحقة؛ لم تتم إضافة أسرار أو اتصال خارجي تلقائيًا.

## ملاحظات مهمة

- الأمر `db:local` يستخدم قاعدة محلية منفصلة عن قاعدة Cloudflare السحابية.
- لا تشغّل `db:remote` إلا بعد التأكد من `database_id` الصحيح.
- لا ترفع ملفات `.env` أو مجلدات `backup-output` أو أي تصدير D1 إلى GitHub.
- الاستعلامات تستخدم bindings، مع تحديد أطوال العنوان والمحتوى لمنع المدخلات غير المناسبة.
- لا توجد حسابات تجريبية متبقية في القاعدة بعد اختبار العزل.

## الاستيراد

من «الإعدادات ← استيراد الملاحظات» يمكن اختيار ملفات متعددة أو مجلد Obsidian. تتم معالجة الملفات داخل المتصفح ثم تُحفظ الملاحظات النصية في حساب المستخدم الحالي. استيراد المرفقات من الخدمات الخارجية ليس تلقائيًا بعد، بينما يمكن إدراج الصور والرسومات الجديدة مباشرة من محرر NotesCloud.

## الصور والرسومات

- `POST /api/assets` — رفع صورة بصيغة Base64 أو SVG نصي (`kind`, `mime`, `filename`, `data` أو `svg`, و`note_id` اختياري).
- `GET /api/assets/:id` — عرض أصل يملكه المستخدم الحالي فقط.
- حد الصورة 5MB وحد SVG 500KB، مع رفض عناصر SVG البرمجية والروابط الخطرة.
- التخزين داخل D1 مناسب للصور الصغيرة والرسومات؛ للصور الكبيرة أو مكتبة وسائط واسعة يفضّل Cloudflare R2 لاحقًا، مع بقاء الرابط داخل الملاحظة.
